# 应用图标

`icon.png` 是 nl2sh助手的图标源图，参考 nl2sh 的 `assets/logo.png` 品牌配色和对话气泡、终端元素。手机与下箭头表示 Android 部署助手。由内置 imagegen 生成，启动器资源从此图按 Android 密度缩放，adaptive icon 使用 inset 留出遮罩安全区域。

生成提示词：

> Use case: logo-brand. Design a polished square Android launcher icon for nl2sh-helper, the Android ADB installer/launcher companion to nl2sh. Input image is brand reference only. Preserve the reference’s dark navy, cyan-blue-violet gradient and lime-green terminal accent. Simplify substantially for recognition at 48px: a bold centered smartphone silhouette with a luminous terminal screen showing only a large lime-green >_ prompt, and a compact white speech bubble attached at the upper-left with two blue horizontal lines, plus a cyan downward deployment arrow entering the phone. The phone and speech bubble should feel like the existing nl2sh identity. Solid full-bleed dark navy background, subtle refined gradients, clean bold forms, all essential imagery centered within the central 60% of the square to survive Android adaptive icon circle/squircle cropping. No wordmark, no letters nl2sh, no badge, no border ring, no rounded outer tile corners, no extra stars, no mockup, no watermark. Render one production icon, 1024x1024.
